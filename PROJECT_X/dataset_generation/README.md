# Dataset Generator

Веб-приложение для генерации датасета вопросов и ответов с использованием Ollama и нейросети Mistral Nemo.

## Возможности

- Генерация вопросов с 5 вариантами ответов на основе текста
- Сохранение вопросов в SQLite базу данных
- Ручное утверждение вопросов через веб-интерфейс
- Экспорт утверждённых вопросов в JSON формате
- Удобный веб-интерфейс с разделением на вкладки

## Требования

- Python 3.8+
- Ollama
- Модель Mistral Nemo

## Установка

### 1. Установите Ollama

Если у вас ещё не установлен Ollama, установите его с [официального сайта](https://ollama.ai).

### 2. Создайте модель из Modelfile

```bash
ollama create dataset-generator -f Modelfile
```

### 3. Проверьте, что модель создана

```bash
ollama list
```

Вы должны увидеть `dataset-generator` в списке моделей.

### 4. Установите Python зависимости

```bash
pip install -r requirements.txt
```

## Запуск

### 1. Запустите Ollama сервер (если ещё не запущен)

```bash
ollama serve
```

### 2. Запустите веб-приложение

```bash
python main.py
```

Приложение будет доступно по адресу: http://localhost:8000

## Использование

### Генерация вопросов

1. Откройте http://localhost:8000 в браузере
2. Вставьте текст в текстовое поле
3. Нажмите "Генерировать вопросы"
4. Подождите, пока нейросеть сгенерирует вопросы

### Утверждение вопросов

1. Перейдите на вкладку "На проверке"
2. Просмотрите сгенерированные вопросы
3. Отметьте чекбоксами вопросы, которые хотите утвердить
4. Нажмите "Утвердить выбранные"

### Удаление вопросов

1. Нажмите кнопку "✕" рядом с вопросом, который хотите удалить
2. Подтвердите удаление

### Экспорт датасета

1. Перейдите на вкладку "Утверждённые"
2. Нажмите "Экспортировать датасет"
3. Файл `dataset.json` будет скачан автоматически

## API Endpoints

- `GET /` - Главная страница
- `POST /api/generate` - Генерация вопросов
- `GET /api/questions?approved_only=false` - Получение вопросов
- `POST /api/approve` - Утверждение вопросов
- `DELETE /api/questions/{id}` - Удаление вопроса
- `GET /api/export` - Экспорт датасета

## Настройка модели

Вы можете изменить параметры модели в файле `Modelfile`:

- `PARAMETER temperature` - Креативность модели (0.0-1.0)
- `PARAMETER num_ctx` - Размер контекста
- `SYSTEM` - Системный промпт для модели

После изменений пересоздайте модель:

```bash
ollama create dataset-generator -f Modelfile
```

## Решение проблем

### Ollama не отвечает

1. Убедитесь, что Ollama сервер запущен: `ollama serve`
2. Проверьте, что модель создана: `ollama list`
3. Проверьте доступность API: `curl http://localhost:11434/api/tags`

### Ошибка "Invalid JSON format"

Модель иногда может генерировать текст вне JSON. Попробуйте:
1. Уменьшить объём входного текста
2. Изменить temperature в Modelfile
3. Повторить генерацию

### База данных не создаётся

Убедитесь, что у приложения есть права на запись в текущую директорию.

## Как добавить реальные скриншоты:
1. Откройте документ в Microsoft Word или LibreOffice Writer
2. Найдите placeholder изображения (серые прямоугольники с надписью "[Место для скриншота]")
3. Удалите placeholder и вставьте вместо него реальный скриншот
4. Подпись к рисунку уже присутствует под каждым placeholder
5. При необходимости отрегулируйте размер изображения

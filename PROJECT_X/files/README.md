### Навигация

- `testing-isolation.html` - Рисунок 5.7: Тестирование изоляции транзакций
- `testing-performance.html` - Рисунок 5.8: График производительности

## 🎯 Как использовать

### Способ 1: Через главную страницу
1. Откройте `index.html` в браузере
2. Выберите нужную страницу из списка
3. Сделайте скриншот

### Способ 2: Напрямую
1. Откройте нужный HTML файл в браузере
2. Настройте размер окна браузера (рекомендуется 1920x1080)
3. Сделайте скриншот

## 📸 Рекомендации по созданию скриншотов

### Размер окна браузера
- **Десктоп**: 1920x1080 или 1440x900
- **Консоль (SQL)**: 1200x800 или полный экран

### Инструменты для скриншотов
- **Windows**: Win + Shift + S (Snipping Tool)
- **macOS**: Cmd + Shift + 4
- **Linux**: Flameshot, Spectacle, или встроенный Screenshot
- **Браузер**: Расширения типа "Full Page Screen Capture"

### Советы
1. Используйте режим "Incognito/Private" для чистоты интерфейса
2. Масштаб браузера должен быть 100% (Ctrl+0 / Cmd+0)
3. Скройте панель закладок браузера (Ctrl+Shift+B / Cmd+Shift+B)
4. Для консольных страниц используйте темный режим по умолчанию

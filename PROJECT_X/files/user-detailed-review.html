Какое ключевое слово используется для исключения дубликатов в результате запроса?
Ваш ответUNIQUE
Правильный ответDISTINCT
DIFFERENT

💡 Пояснение
Ключевое слово DISTINCT используется в SELECT-запросах для исключения дубликатов из результирующего набора. Синтаксис: SELECT DISTINCT column_name FROM table_name. UNIQUE используется для создания ограничений уникальности на уровне таблицы.

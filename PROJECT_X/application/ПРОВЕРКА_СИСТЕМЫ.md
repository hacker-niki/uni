## 📊 Endpoints API

### Авторизация
- `POST /api/auth/login` - Вход по email
- `GET /api/auth/me` - Текущий пользователь
- `GET /api/auth/users` - Список пользователей

### Вопросы
- `GET /api/questions` - Список вопросов
- `GET /api/questions/{id}` - Конкретный вопрос
- `POST /api/questions/{id}/approve` - Одобрить вопрос
- `DELETE /api/questions/{id}` - Удалить вопрос

### Документы
- `GET /api/documents` - Список документов

### Тесты
- `GET /api/tests` - Список тестов
- `GET /api/tests/{id}` - Детали теста
- `GET /api/tests/{id}/questions` - Вопросы теста

### Служебные
- `GET /` - Информация об API
- `GET /health` - Health check
- `GET /docs` - Swagger UI
- `GET /api/stats/overview` - Статистика

## 🆘 Решение проблем

### Проблема: Сервисы не запускаются
```bash
docker-compose down
docker-compose up -d
```

### Проблема: База данных не подключается
```bash
docker-compose restart db
docker-compose logs db
```

### Проблема: Frontend не загружается
```bash
docker-compose restart frontend
docker-compose logs frontend
```

### Проблема: Авторизация не работает
```bash
# Проверить backend
curl http://localhost:8000/health

# Проверить логи
docker-compose logs backend

# Перезапустить backend
docker-compose restart backend
```

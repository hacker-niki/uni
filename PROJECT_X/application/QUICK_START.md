# 🚀 Быстрый старт TestGen MVP

## Запуск за 3 шага

### 1. Перейдите в папку проекта
```bash
cd application
```

### 2. Запустите приложение
```bash
# Вариант А: Используя скрипт (рекомендуется)
./start.sh

# Вариант Б: Напрямую через docker-compose
docker-compose up --build
```

### 3. Откройте в браузере
- **Приложение**: http://localhost:3000
- **API**: http://localhost:8000
- **API Документация**: http://localhost:8000/docs

---

## Что вы увидите

### Главная страница (Dashboard)
- Статистика: 10 вопросов, 2 документа, 1 тест
- Карточки с информацией о системе

### Документы
- Список загруженных документов
- Статусы обработки
- Количество сгенерированных вопросов

- 10 захардкоженных вопросов по SQL
- Вкладки: "На проверке" и "Одобренные"

### Тесты
- Карточка теста "Основы SQL"
- 10 вопросов, 45 минут
- Проходной балл 70%

### Прохождение теста
- Таймер отсчета времени
- Навигация по вопросам
- Прогресс-бар
- Визуальная индикация отвеченных вопросов
- Результат с процентами и анимацией

## Возможные проблемы

### Порты заняты
Если порты 3000 или 8000 заняты:

1. Остановите процессы на этих портах
2. Или измените порты в `docker-compose.yml`:
```yaml
ports:
  - "3001:3000"  # вместо 3000:3000
  - "8001:8000"  # вместо 8000:8000
```

### Docker не запускается
```bash
# Проверьте статус Docker
sudo systemctl status docker

# Запустите Docker
sudo systemctl start docker
```

## Презентация

### Сценарий демонстрации:

1. **Главная страница** (10 сек)
   - Показать статистику
   - Объяснить назначение системы

2. **Документы** (15 сек)
   - Показать список документов
   - Объяснить процесс обработки

3. **Вопросы** (30 сек)
   - Переключить вкладки
   - Одобрить 1-2 вопроса
   - Показать правильные ответы

4. **Прохождение теста** (45 сек)
   - Начать тест
   - Показать таймер и навигацию
   - Ответить на несколько вопросов
   - Завершить и показать результат

**Общее время: ~2 минуты**

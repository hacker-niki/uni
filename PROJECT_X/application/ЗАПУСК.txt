1. Откройте терминал в папке application/

2. Выполните команду:

   ./start.sh

   ИЛИ:

   docker-compose up --build

3. Дождитесь запуска (1-2 минуты при первом запуске)

4. Откройте в браузере:

   http://localhost:3000

✓ Главная страница      - Статистика системы

┌───────────────────────────────────────────────────────────────┐
│ ДЛЯ ПРЕЗЕНТАЦИИ                                               │
└───────────────────────────────────────────────────────────────┘

Сценарий демонстрации (2 минуты):

1. Главная (10 сек)
   → Показать статистику: 10 вопросов, 2 документа, 1 тест

2. Документы (15 сек)
   → Показать список с статусами обработки

3. Вопросы (30 сек)
   → Переключить вкладки "На проверке" / "Одобренные"
   → Одобрить 1-2 вопроса
   → Показать правильные ответы (зеленым)

4. Прохождение теста (45 сек)
   → Нажать "Начать тест"
   → Показать таймер и навигацию
   → Ответить на 2-3 вопроса
   → Завершить и показать результат с анимацией


┌───────────────────────────────────────────────────────────────┐
│ ОСТАНОВКА                                                     │

docker-compose down

→ Измените порты в docker-compose.yml

Docker не запускается:
→ sudo systemctl start docker

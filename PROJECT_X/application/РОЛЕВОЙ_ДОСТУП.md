# Ролевой доступ в TestGen MVP

## Выполненные работы

### ✅ 1. Обновление ProtectedRoute

**Файл:** `frontend/src/components/ProtectedRoute.jsx`

Добавлена поддержка проверки ролей через параметр `allowedRoles`:

```javascript
function ProtectedRoute({ children, allowedRoles }) {
  const { isAuthenticated, loading, user } = useAuth()

  // Проверка авторизации
  if (!isAuthenticated) {
    return <Navigate to="/login" replace />
  }

  // Проверка ролей
  if (allowedRoles && allowedRoles.length > 0) {
    const userRoles = user?.roles || []
    const hasRequiredRole = allowedRoles.some(role => userRoles.includes(role))

    if (!hasRequiredRole) {
      return <Navigate to="/" replace />
    }
  }

  return children
}
```

### ✅ 3. Ограничения доступа к маршрутам

**Файл:** `frontend/src/App.jsx`

Настроены ограничения доступа к разделам:

```javascript
<Routes>
  <Route path="/" element={<Dashboard />} />

  {/* Документы - только для admin и teacher */}
  <Route path="/documents" element={
    <ProtectedRoute allowedRoles={['admin', 'teacher']}>
      <Documents />
    </ProtectedRoute>
  } />

  {/* Вопросы - только для admin и teacher */}
  <Route path="/questions" element={
    <ProtectedRoute allowedRoles={['admin', 'teacher']}>
      <Questions />
    </ProtectedRoute>
  } />

  {/* Тесты - доступны всем */}
  <Route path="/tests" element={<Tests />} />
  <Route path="/tests/:id/take" element={<TakeTest />} />
</Routes>
```

### ✅ 4. Адаптивное меню Sidebar

**Файл:** `frontend/src/App.jsx`

Меню отображает только доступные разделы в зависимости от роли:

```javascript
function Sidebar() {
  const { user, logout } = useAuth()
  const userRole = user?.roles?.[0]

  const canAccessDocuments = userRole === 'admin' || userRole === 'teacher'
  const canAccessQuestions = userRole === 'admin' || userRole === 'teacher'

  return (
    <nav className="nav">
      <Link to="/">🏠 Главная</Link>

      {canAccessDocuments && (
        <Link to="/documents">📄 Документы</Link>
      )}

      {canAccessQuestions && (
        <Link to="/questions">❓ Вопросы</Link>
      )}

      <Link to="/tests">📝 Тесты</Link>
    </nav>
  )
}
```

## Особенности для каждой роли

### 👨‍💼 Администратор (admin)

**Может:**
- ✅ Видеть полную статистику системы (включая количество пользователей)
- ✅ Загружать документы
- ✅ Проверять и одобрять вопросы
- ✅ Создавать и управлять тестами
- ✅ Видеть всех пользователей системы

**Видит в меню:**
- Главная
- Документы
- Вопросы
- Тесты

### 👨‍🏫 Преподаватель (teacher)

**Может:**
- ✅ Загружать документы для генерации вопросов
- ✅ Проверять и одобрять автоматически сгенерированные вопросы
- ✅ Создавать тесты из одобренных вопросов
- ✅ Управлять своими тестами
- ✅ Назначать тесты студентам

**Видит в меню:**
- Главная
- Документы
- Вопросы
- Тесты

### 🎓 Студент (student)

**Может:**
- ✅ Видеть список доступных для него тестов
- ✅ Проходить назначенные тесты
- ✅ Видеть свою статистику

**Не может:**
- ❌ Загружать документы
- ❌ Создавать или редактировать вопросы
- ❌ Создавать тесты
- ❌ Видеть чужие результаты

**Видит в меню:**
- Главная (со списком доступных тестов)
- Тесты (только для прохождения)

## Механизм защиты

### 1. Защита на уровне маршрутов

Компонент `ProtectedRoute` проверяет роли пользователя:

```javascript
// Если роль не подходит → редирект на главную
if (!hasRequiredRole) {
  return <Navigate to="/" replace />
}
```

### 2. Условное отображение меню

Пункты меню скрыты для студентов:

```javascript
{canAccessDocuments && (
  <Link to="/documents">📄 Документы</Link>
)}
```

### 3. Разные Dashboard

Каждая роль видит свой интерфейс главной страницы:

```javascript
if (userRole === 'admin') return <AdminDashboard />
if (userRole === 'teacher') return <TeacherDashboard />
if (userRole === 'student') return <StudentDashboard />
```

## Сценарии использования

### Сценарий 1: Студент пытается зайти на страницу "Документы"

1. Студент авторизован с ролью `student`
2. В меню нет пункта "Документы"
3. Если попытается напрямую ввести URL `/documents`:
   - `ProtectedRoute` проверит роли
   - Обнаружит, что `student` не в списке `['admin', 'teacher']`
   - Сделает редирект на `/` (главную)

### Сценарий 2: Преподаватель создает тест

1. Преподаватель авторизуется с ролью `teacher`
2. Видит "Панель преподавателя" с статистикой
3. В меню доступны: Главная, Документы, Вопросы, Тесты
4. Может загрузить документ → проверить вопросы → создать тест

### Сценарий 3: Студент проходит тест

1. Студент авторизуется с ролью `student`
2. Видит "Панель студента" со списком доступных тестов
3. В меню доступны только: Главная, Тесты
4. Нажимает "Начать тест" → проходит тест

## Описание компонентов

### Backend (FastAPI)

**main.py** - Единственный файл backend'а содержит:
- Модели данных (Pydantic)
- Захардкоженные демо-данные
- Все API endpoints
- CORS конфигурацию для работы с React

### Frontend (React)

#### Главные файлы:
- **main.jsx** - Инициализация React приложения
- **App.jsx** - Роутинг и навигация (sidebar)
- **index.css** - CSS переменные и глобальные стили

#### Страницы:

**Dashboard** (Главная)
- Статистика в 4 карточках
- Информация о системе
- Быстрые ссылки

**Documents** (Документы)
- Список загруженных документов
- Статусы обработки
- Неактивная форма загрузки (MVP)

**Questions** (Вопросы)
- Табы: "На проверке" / "Одобренные"
- Карточки вопросов с ответами
- Кнопки: Одобрить / Удалить
- Правильные ответы выделены зеленым

**Tests** (Тесты)
- Сетка с карточками тестов
- Информация: вопросы, время, проходной балл
- Кнопка "Начать тест"

**TakeTest** (Прохождение теста)
- Хедер с таймером
- Прогресс-бар
- Навигация по вопросам (1-20)
- Визуальная индикация ответов
- Страница результата с анимацией

## Дизайн

### Цветовая схема:
```css
--primary: #667eea        /* Фиолетовый */
--secondary: #764ba2      /* Темно-фиолетовый */
--success: #10b981        /* Зеленый */
--warning: #f59e0b        /* Оранжевый */
--danger: #ef4444         /* Красный */
--dark: #0f172a           /* Почти черный */
--gray-50 до gray-800     /* Оттенки серого */
```

### Типографика:
- **Основной шрифт**: Manrope (Google Fonts)
- **Код**: JetBrains Mono

### Стиль:
- Градиентные кнопки (#667eea → #764ba2)
- Скругленные углы (border-radius: 10-16px)
- Мягкие тени (box-shadow)
- Анимации и transitions (0.3s)
- Hover эффекты

## Для разработчиков

### Добавление новых вопросов:
Отредактируйте массив `MOCK_QUESTIONS` в `backend/main.py`

### Изменение дизайна:
Измените CSS переменные в `frontend/src/index.css`

### Добавление страницы:
1. Создайте компонент в `frontend/src/pages/`
2. Добавьте роут в `frontend/src/App.jsx`
3. Добавьте ссылку в Sidebar

### Изменение портов:
Отредактируйте `docker-compose.yml`

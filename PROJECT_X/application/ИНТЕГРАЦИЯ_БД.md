# Отчет об интеграции базы данных в проект TestGen

## Выполненные работы

### ✅ 1. Обновление docker-compose.yml

Добавлен сервис MariaDB 11.2 с автоматической инициализацией:

- Контейнер `testgen-db` с базой данных MariaDB
- Автоматическая инициализация из файла `database/init.sql`
- Health check для контроля готовности БД
- Persistent volume для хранения данных
- Переменные окружения для backend

### ✅ 2. Разработка структуры базы данных

Создан файл `database/init.sql` с полной структурой БД согласно дипломной работе:

**Таблицы (14 шт):**
- `roles` - Роли пользователей
- `users` - Пользователи системы
- `user_roles` - Связь пользователей и ролей
- `groups` - Группы пользователей
- `user_groups` - Связь пользователей и групп
- `source_documents` - Исходные документы
- `questions` - Вопросы для тестов
- `answer_options` - Варианты ответов
- `tests` - Тесты
- `test_questions` - Связь тестов и вопросов
- `test_assignments` - Назначение тестов
- `test_sessions` - Сессии прохождения
- `user_answers` - Ответы пользователей
- `audit_log` - Журнал аудита

**Особенности реализации:**
- Все таблицы с ENGINE=InnoDB для поддержки транзакций
- Кодировка utf8mb4 для поддержки всех символов Unicode
- Внешние ключи с правильными правилами CASCADE/SET NULL
- Индексы на часто используемых полях
- Комментарии к полям для документации

### ✅ 3. Триггеры и хранимые процедуры

**Триггеры:**
- `trg_questions_approve` - Автоматическое обновление времени одобрения
- `trg_test_sessions_complete` - Автоматический расчет результатов теста
- Триггеры аудита для tables: users, tests, test_sessions (INSERT/UPDATE/DELETE)

**Хранимые процедуры:**
- `sp_get_user_assigned_tests` - Получение тестов пользователя
- `sp_get_test_questions` - Получение вопросов теста
- `sp_calculate_test_score` - Подсчет результатов
- `sp_get_user_statistics` - Статистика пользователя

### ✅ 4. Система аудита

Реализована полная система аудита изменений:

- Таблица `audit_log` с хранением данных в JSON формате
- Автоматические триггеры на INSERT/UPDATE/DELETE
- Отслеживание старых и новых значений
- Привязка к пользователю, выполнившему операцию

### ✅ 6. Backend интеграция

**Файлы Python:**

#### `backend/database.py`
- Настройка подключения к MariaDB через SQLAlchemy
- Connection pooling для оптимизации
- Dependency `get_db()` для FastAPI
- Функции инициализации и проверки подключения

#### `backend/models.py`
- Полные ORM модели для всех таблиц
- Relationships между моделями
- Enum типы для статусов
- 600+ строк кода с документацией

#### `backend/auth.py`
- Упрощенная авторизация по email (без пароля для MVP)
- OAuth2 схема для токенов
- Dependencies для защиты endpoints
- Проверка ролей пользователей

#### `backend/main.py`
- Интеграция всех моделей
- API endpoints для работы с БД
- Полная замена mock данных на реальные запросы к БД

### ✅ 7. API Endpoints

**Авторизация:**
- `POST /api/auth/login` - Вход по email
- `GET /api/auth/me` - Текущий пользователь
- `GET /api/auth/users` - Список пользователей

**Вопросы:**
- `GET /api/questions` - Список с фильтрацией и пагинацией
- `GET /api/questions/{id}` - Конкретный вопрос
- `POST /api/questions/{id}/approve` - Одобрение вопроса
- `DELETE /api/questions/{id}` - Удаление вопроса

**Документы:**
- `GET /api/documents` - Список загруженных документов

**Тесты:**
- `GET /api/tests` - Список тестов
- `GET /api/tests/{id}` - Детали теста
- `GET /api/tests/{id}/questions` - Вопросы теста

**Служебные:**
- `GET /` - Информация об API
- `GET /health` - Health check с проверкой БД
- `GET /docs` - Swagger UI документация
- `GET /api/stats/overview` - Статистика системы
